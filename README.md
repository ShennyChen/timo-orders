# Timo 烘焙坊（堤默烘焙）

沁沁與你共同經營的家庭烘焙事業 —— 營運資料、系統與文件。

## 資料夾結構

```
生成/              App 與產出，依四個經營面向分類
├── 官方line/       LINE 官方帳號：圖文選單、客服、下單入口
├── 網站/           品牌展示頁面（尚未建立）
├── 訂單管理app/     雙人共用訂單 PWA ← 目前唯一已運作的系統
└── google地圖/      Google 商家檔案（尚未評估）

規則/              營運手冊、開發紀錄、分析報告
├── 營運與開發整合紀錄.md
└── 訂單資料分析.md

raw/               原始素材，未經加工，請勿編輯
```

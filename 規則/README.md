## 先讀哪一份

- **任何新對話** → 先讀工作約定

- 想知道**整體計畫與下一步** → 營運與開發整合紀錄（第 01 節執行摘要、第 11 節待辦）
- 想知道**系統現在有什麼問題** → 訂單資料分析（第 3 節）、整合紀錄第 10 節風險表
- 想知道**賣什麼、多少錢** → 產品價目表
- 想知道**該問沁沁什麼** → 整合紀錄第 12 節（價格部分已由價目表補上）

## 重要前提

試算表中目前的訂單**全部是測試資料**，不是真實顧客訂單。
正式處理真實資料前，應先完成整合紀錄第 10 節列出的高優先安全項目。

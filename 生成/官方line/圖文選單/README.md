## 設計

配色直接取自品牌既有素材，不是另外挑的：

| 色 | 取自 |
| :--- | :--- |
| 深灰褐 `#6B615C` | logo 的剪影與字 |
| 淡玫瑰 `#CE9398` | 菜單海報的外框 |
| 金 `#C8B183` | 菜單海報的麥穗 |
| 米白 `#FDFBF8` | 海報底色 |

字體 Noto Serif TC，與海報的手寫感較接近。
每張都有雙層細框（玫瑰＋金）與一個葉片飾紋，呼應 logo 的藤蔓裝飾。

有照片的三格，照片都壓了一層 74% 米白並降飽和度到 60%，
讓字清楚但照片仍看得出內容。

### 字級

圖文選單在手機上只有約 390px 寬，每格縮到約 130px，所以字要比直覺大很多。
字級依字數自動調整，確保不會被框線裁掉：

| 字數 | 字級 |
| :--- | ---: |
| 2 字（蛋糕） | 250px |
| 3 字（雪花酥） | 195–200px |
| 4 字（節日禮盒、訂購須知、聯絡我們） | 160px |

價格 200px、規格 88px、「每週特賞」標籤 60px。
產生圖片時會自動檢查文字有沒有超出框線，有的話會在終端機警告。

## 每週要換的那張

每週特賞每週換一次。傳新照片過來，告訴我品名、容量與價格即可。

也可以自己改 `產生圖片.js` 最下面的 `JOBS`：

```js
{f:'1-1_1-2_每週特賞_雪花酥.png', w:1686, h:843,
 html:weekly('雪花酥', b64('snow'), '850g／包', '200元')},
```

`weekly(品名, 照片, 規格, 價格)`。照片要先縮成 1100×1100 的 jpg、
轉 base64 存成 `<名稱>.b64` 放在同一層，再執行 `node 產生圖片.js`。

> 品名以這裡寫的為準。注意菜單海報上印的是「雪花**餅**」，
> 而這張用的是「雪花**酥**」—— 兩者要統一，見 規則/產品價目表.md 第六節。

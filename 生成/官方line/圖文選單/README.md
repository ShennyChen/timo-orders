## 怎麼產生的

**先排出完整的 2500 × 1686 一整張，再切成五塊。**

這點很重要：如果五張各自畫，底色紋理、分線位置、照片邊緣都會對不齊，
拼起來一眼就看得出是六塊拼湊的。從同一張切，接縫一定準。

`產生圖片.js` 會自動做完整流程：排版 → 截圖整張 → 切成五塊 →
另存一份 `_組合預覽_2500x1686.png`（只是給人看的，**不要上傳**）。

### 古典精緻的做法

不靠放大、不靠加色，靠**裝飾結構**和**線條的細**：

| 元素 | 做法 |
| :--- | :--- |
| 整幅外框 | 金色雙線（3px＋1.5px），四角各一個捲葉角飾 |
| 標題上方 | 捲葉紋（金） |
| 標題下方 | 細飾線：中央菱形＋兩側細線＋端點圓珠 |
| 字重 | 700 而非 900，字距 0.14em |
| 分線 | 7px，比先前細 |

外框是整幅一起畫的，切成五塊之後每塊各自帶著自己那一段，拼起來才連得上。

---

### 讓它看起來是一整塊

| 做法 | 原因 |
| :--- | :--- |
| 沒有每格各自的外框 | 有框就會變成六張卡片 |
| 全版共用一層淡紙紋 | 同一塊材質，而不是六塊拼起來 |
| 分線只畫在真正的格線上 | 上排只有一條（因為前兩格是合併的） |
| 分線兩端內縮 62px | 不碰到邊緣，看起來是切分而不是框線 |
| 「雪花酥」照片右緣做漸層 | 不然硬邊會被誤認成分線，以為上排有三格 |

分線寬 9px、深灰褐 `#5A5049`。看起來很粗，但縮到手機上只剩約 1.4px，
再細就看不見了。

### 捲葉紋

照 logo 的**語彙**做的，不是照抄。把 logo 放大看，兩側是巴洛克捲葉紋 ——
捲曲的渦卷配飽滿尖葉、左右對稱、實心填色。

同一套語彙做成繁簡兩版，依位置長短挑：

| 版本 | 用在 | 組成 |
| :--- | :--- | :--- |
| 繁版 | 橫向長分線（2376px） | 中央棕櫚葉＋上下尖葉＋外側渦卷＋端點圓珠 |
| 簡版 | 直向分線、格內飾紋 | 中央棕櫚葉＋上下尖葉＋端點圓珠 |

分線結構是「線—紋飾—線」：兩段線用 flex 撐開、紋飾固定寬度，
所以不管分線多長，紋飾都不會被拉變形。

**直向紋飾不是把橫的用 CSS 轉 90 度。** 那樣元素的佔位框不會跟著轉，
渦卷會跑出線外變成飄在旁邊的鉤子。正確做法是在 SVG 內部旋轉內容、
同時交換 viewBox 與寬高，讓佔位框也是直的。

產生圖片時會檢查每個紋飾有沒有超出所屬分線的框，有的話在終端機警告。

## 設計

配色直接取自品牌既有素材，不是另外挑的：

| 色 | 取自 |
| :--- | :--- |
| 深灰褐 `#4E463F` | logo 的剪影與字 |
| 分線 `#5A5049` | 同上，略深 |
| 淡玫瑰 `#A8646D` | 菜單海報的外框（加深以利辨識） |
| 金 `#BFA571` | 菜單海報的麥穗 |
| 米白 `#FCF9F5` | 海報底色 |

字體 Noto Serif TC，與海報的手寫感較接近，每格有一個葉片飾紋呼應 logo 的藤蔓。

有照片的三格，照片都壓了一層 78% 米白並降飽和度到 50%，
讓字清楚但照片仍看得出內容。

### 字級

圖文選單在手機上只有約 390px 寬，每格縮到約 130px，所以字要比直覺大很多。
字級依字數自動調整，確保不會被切到：

| 字數 | 字級 |
| :--- | ---: |
| 2 字（蛋糕） | 235px |
| 3 字（雪花酥） | 185px |
| 4 字（節慶禮盒、訂購須知、聯絡我們） | 148px |

字重用 700 而非最粗的 900，字距拉到 0.14em —— 太粗太擠會變得現代而笨重，
古典襯線要留得出呼吸的空間。

「本週特賞」84px，規格 74px，**價格 132px**。
價格刻意不做大：數字一大就壓過整個版面，變成特價傳單而不是品牌選單。

產生時會檢查文字與紋飾有沒有超出框，有的話會在終端機警告。

## 每週要換的那張

本週特賞每週換一次。傳新照片過來，告訴我品名、容量與價格即可。

也可以自己改 `產生圖片.js` 最下面的 `JOBS`：

```js
{f:'1-1_1-2_本週特賞_雪花酥.png', w:1686, h:843,
 html:weekly('雪花酥', b64('snow'), '850g／包', '200元')},
```

`weekly(品名, 照片, 規格, 價格)`。照片要先縮成 1100×1100 的 jpg、
轉 base64 存成 `<名稱>.b64` 放在同一層，再執行 `node 產生圖片.js`。

> 品名以這裡寫的為準。注意菜單海報上印的是「雪花**餅**」，
> 而這張用的是「雪花**酥**」—— 兩者要統一，見 規則/產品價目表.md 第六節。

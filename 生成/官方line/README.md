## 六格圖文選單（規劃中）

| 第一排 | 第二排 |
| :--- | :--- |
| ① 每週產品：本週品項／優惠 | ④ 我要訂購：進入訂購流程 |
| ② 客製化產品：生日蛋糕等洽詢 | ⑤ 訂購須知：付款、取貨、截止日 |
| ③ 節日產品：節慶禮盒 | ⑥ 聯絡我們：客服與諮詢 |

## 在整體流程中的位置

LINE 是**核心客服與下單入口**，兩條路徑：

- 每週／節日產品 → 共用 Google 表單 → Google Sheets → 訂單 App
- 客製化產品 → LINE 討論需求與報價 → 人工確認 → App 手動建單
